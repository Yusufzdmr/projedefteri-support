# ProjeDefteri Destek

ProjeDefteri ile ilgili destek, hata bildirimi ve öneriler için bu sayfada GitHub Issues bölümünü kullanabilirsiniz.

## Destek

Bir sorun yaşarsanız lütfen işletim sistemi, uygulama sürümü ve karşılaştığınız hata mesajını yazarak yeni bir destek talebi oluşturun.

## Gizlilik

ProjeDefteri uygulaması proje, bütçe, gelir, gider ve ödeme bilgilerini cihazda saklar. Kullanıcının etkinleştirdiği iCloud eşleme ve paylaşım özellikleri Apple iCloud/CloudKit altyapısını kullanır.

## Uygulama

- Bundle ID: `com.projedefteri.app`
- iOS sürümü: 1.0
